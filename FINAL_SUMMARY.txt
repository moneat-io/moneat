PROJECT OVERVIEW
--------------------------------------------------------------------------------
A production-ready Sentry alternative built from scratch with:
  • Full Sentry SDK compatibility (90+ platform SDKs work out of the box)
  • Modern stack: Kotlin/Ktor backend + React frontend
  • ClickHouse for high-performance event analytics (10-100x compression)
  • Cost-effective VPS deployment ($33/month target)
  • Focus on mobile monitoring

API ENDPOINTS
--------------------------------------------------------------------------------
PUBLIC (No Authentication):
  POST   /auth/signup                    Create new user account
  POST   /auth/login                     Login and get JWT token
  POST   /api/{projectId}/envelope/      Ingest Sentry envelope
  POST   /api/{projectId}/store/         Ingest Sentry event (legacy)
  GET    /api/{projectId}/security/      CORS preflight
  GET    /health                         Health check

AUTHENTICATED (JWT Required):
  GET    /api/v1/projects                List user's projects
  GET    /api/v1/projects/{id}           Get project details
  GET    /api/v1/projects/{id}/issues    List project issues
  GET    /api/v1/issues/{id}             Get issue detail
  GET    /api/v1/issues/{id}/events      Get issue events
  GET    /api/v1/projects/{id}/stats     Get project statistics

GETTING STARTED
--------------------------------------------------------------------------------
1. Prerequisites:
   • Docker & Docker Compose
   • Java 17+ (for backend development)
   • Node.js 18+ (for frontend development)

2. Quick Start (3 commands):
   ./setup.sh                           # Start infrastructure
   cd backend && ./gradlew run          # Start API (port 8080)
   cd dashboard && npm install && npm run dev  # Start UI (port 3000)

3. Test:
   ./test-api.sh                        # Run automated tests
   
4. Open browser:
   http://localhost:3000                # Dashboard
   
5. Login with test credentials or create new account

6. Send a test error:
   curl -X POST http://localhost:8080/api/1/store/ \
     -H "X-Sentry-Auth: Sentry sentry_key=abc123def456, sentry_version=7" \
     -H "Content-Type: application/json" \
     -d '{"event_id":"test","timestamp":'$(date +%s)',"level":"error","platform":"javascript","message":"Test error","exception":{"values":[{"type":"Error","value":"Test"}]}}'

KNOWN LIMITATIONS (MVP)
--------------------------------------------------------------------------------
• No password reset flow
• No email verification
• No session refresh tokens (1-hour expiry only)
• No rate limiting (vulnerable to abuse)
• Basic fingerprinting (could miss duplicate issues)
• No source map support (JavaScript errors not symbolicated)
• No native crash symbolication (iOS/Android)
• No project creation UI (requires SQL)
• No team management
• No integrations (Slack, Discord, etc.)
• No advanced search/filtering
• Limited error context display
