
# Moneat Documentation

Moneat is a Sentry-compatible observability platform for error monitoring, incident management, uptime tracking, and structured logging. Use any existing Sentry SDK to get started in minutes.

<a href="/docs/getting-started" className="inline-block px-6 py-3 bg-sky-500 hover:bg-sky-600 !text-white font-semibold rounded-lg transition-colors no-underline">Get Started →</a>

## Features

- [Error Monitoring](/docs/error-monitoring) — Capture and track errors in real-time using Sentry-compatible SDKs
- [Issue Tracking](/docs/issue-tracking) — Group, triage, and resolve issues with automatic fingerprinting
- [On-Call & Incidents](/docs/on-call) — Set up schedules, escalation policies, and manage incidents
- [Uptime Monitoring](/docs/uptime-monitoring) — Monitor your endpoints with HTTP checks and heartbeats
- [Structured Logging](/docs/logging) — Ingest, search, and tail logs via OTLP and WebSocket
- [Status Pages](/docs/status-pages) — Create public status pages to communicate incidents to users
- [Releases & Source Maps](/docs/releases) — Track deployments and upload source maps for readable stack traces
- [Integrations](/docs/integrations) — Connect Slack, Discord, and webhooks for notifications
- [AI Observability](/docs/ai-observability) — Monitor LLM applications, trace agent executions, and track token costs
