# Environment Variables Setup

The Moneat backend supports loading environment variables from a `.env` file at the project root.

## Quick Start

1. Copy the example file:
   ```bash
   cp .env.example .env
   ```

2. Edit `.env` with your local configuration values

3. Start the backend - it will automatically load the `.env` file

## How it Works

The backend checks for environment variables in this order:
1. **System environment variables** (highest priority)
2. **`.env` file** at project root (fallback)
3. **Default values** in `application.conf` (last resort)

This means you can override `.env` values by setting system environment variables.

## Configuration

The `.env` file supports all the same variables that can be set via `application.conf`:

- `PORT` - Server port (default: 8080)
- `DATABASE_URL` - PostgreSQL connection URL
- `DATABASE_USER` - PostgreSQL username
- `DATABASE_PASSWORD` - PostgreSQL password
- `CLICKHOUSE_URL` - ClickHouse server URL
- `CLICKHOUSE_USER` - ClickHouse username
- `CLICKHOUSE_PASSWORD` - ClickHouse password
- `REDIS_URL` - Redis connection URL
- `JWT_SECRET` - Secret key for JWT tokens
- `EMAIL_FROM` - Email sender address
- `FRONTEND_URL` - Frontend URL for email links
- `AWS_REGION` - AWS region for SES
- `AWS_ACCESS_KEY_ID` - AWS access key
- `AWS_SECRET_ACCESS_KEY` - AWS secret key
- `LEGAL_TERMS_VERSION` - Current terms of use version required at signup
- `LEGAL_PRIVACY_VERSION` - Current privacy policy version required at signup
- `VITE_LEGAL_TERMS_VERSION` - Frontend-exposed terms version sent at signup
- `VITE_LEGAL_PRIVACY_VERSION` - Frontend-exposed privacy version sent at signup
- `GITHUB_VERSIONS_CACHE_TTL_SECONDS` - Redis cache TTL (seconds) for SDK version lookups

## Usage in Code

To use the EnvConfig in your Kotlin code:

```kotlin
import com.moneat.config.EnvConfig

// Get a value (returns null if not found)
val apiKey = EnvConfig.get("API_KEY")

// Get a value with a default
val port = EnvConfig.get("PORT", "8080")

// Check if .env file was loaded
if (EnvConfig.isLoaded()) {
    println(".env file found and loaded")
}
```

## Security Notes

- ⚠️ **Never commit `.env` files** - they are already in `.gitignore`
- Use `.env.example` as a template (safe to commit, no secrets)
- For production, use system environment variables or a secrets manager
