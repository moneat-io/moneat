# Moneat Documentation

Moneat is a Sentry-compatible observability platform for error monitoring, incident management, uptime tracking, and structured logging. Use any existing Sentry SDK to get started in minutes.

## Features

- [Error Monitoring](/error-monitoring) — Capture and track errors in real-time using Sentry-compatible SDKs
- [Issue Tracking](/issue-tracking) — Group, triage, and resolve issues with automatic fingerprinting
- [On-Call & Incidents](/on-call) — Set up schedules, escalation policies, and manage incidents
- [Uptime Monitoring](/uptime-monitoring) — Monitor your endpoints with HTTP checks and heartbeats
- [Structured Logging](/logging) — Ingest, search, and tail logs via OTLP and WebSocket
- [Status Pages](/status-pages) — Create public status pages to communicate incidents to users
- [Releases & Source Maps](/releases) — Track deployments and upload source maps for readable stack traces
- [Integrations](/integrations) — Connect Slack, Discord, and webhooks for notifications
- [AI Observability](/ai-observability) — Monitor LLM applications, trace agent executions, and track token costs
